# Courses

One directory per course. `docs/conventions/skills-and-docs.md` says what each directory holds.

| Course | Topic |
|---|---|
| `card-game/` | Card game systems: the rules core, card data, effects, resolution and tooling |
| `architecture/` | Codebase architecture: where code goes, the convention docs and lint rules for it |

A session's opening message names its course, as in "continue the architecture course". A session
that names none, course or not, reads `card-game/COURSE.md`.
